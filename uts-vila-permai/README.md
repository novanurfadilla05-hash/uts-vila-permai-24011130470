## Deskripsi
Vila Permai adalah aplikasi web satu halaman untuk menampilkan pilihan villa dan melakukan simulasi pemesanan penginapan.

## Fitur
- Menampilkan tiga data villa dari array objek JavaScript.
- Pencarian villa berdasarkan nama, lokasi, atau jenis.
- Form pemesanan dengan pilihan villa.
- Validasi nama, tanggal, jumlah tamu, dan kapasitas villa.
- Menghitung estimasi biaya berdasarkan harga per malam dan lama menginap.
- Menyimpan nama tamu terakhir dan riwayat pesanan menggunakan localStorage.
- Tampilan responsif untuk desktop, tablet, dan ponsel.

## Teknologi
- HTML5
- CSS3
- JavaScript

## Cara Menjalankan
1. Unduh atau clone repository.

3. Klik dua kali `index.html`, atau buka file tersebut melalui browser.
4. Tidak diperlukan instalasi server atau database untuk menjalankan versi statis ini.
